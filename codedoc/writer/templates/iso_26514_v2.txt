2. **Never restate the signature in prose.** The parameter table is the reference; prose that
   repeats it is scored as redundancy.
3. **No invented facts.** Every claim must be traceable to the source above, the evidence
   blocks, or the metadata provided. Do not state a version, release date, author, license,
   or benchmark, and do not describe behaviour the source does not show.
4. **Cover all five fact families** or say the source does not show them: what it does;
   inputs (name, type, default, constraint); outputs (every return path); failures (every
   raised or propagated exception); side effects (mutations, I/O, network, subprocess).
5. **Length budget: 120–250 words for a function or method, 250–450 for a class.** Filler
   costs Conciseness and buys nothing.
6. **Declare one content type.** This artefact is **Reference** content. Procedural material
   appears only as a code example under Usage, never as numbered instructions.
7. **Structured data goes in tables**, not prose: parameters, returns, errors, attributes.
8. **Heading depth is H1 then H2 only.** No H3, no skipped levels.
